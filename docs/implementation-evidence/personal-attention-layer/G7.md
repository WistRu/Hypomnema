## Exact-capture and summary invariants

Accepted automated evidence proves:

- relay protocol v5 keeps v3/v4 activation, close, workspace and state
  commands compatible;
- capture scope includes installation, browser session, native browser tab,
  instance row, expected URL, instance revision and `firstSeenAt` ABA guard;
- the extension re-reads the native tab immediately before extraction;
- server ingest is bound to a live relay grant and request id, is origin
  checked, single-use and idempotent;
- blank or unsupported extraction fails without replacing prior content;
- offline, timeout and outcome-unknown paths are recoverable and do not invent
  success;
- navigated and closed targets return typed recoverable failures;
- web selection is an immutable physical-copy value captured at dispatch;
- concurrent instance refresh cannot retarget an in-flight operation;
- Short and Deep jobs carry their source content revision, and stale job
  results cannot overwrite the current page state;
- the legacy Library short-summary action remains unchanged;
- no G7 path uses `window.open`, `location.href` or URL-based fallback.
