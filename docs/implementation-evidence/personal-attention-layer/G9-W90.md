## Accepted product boundary

W90 adds the Resource-only first-party surface for live research without a new
top-level route. The UI:

- obtains a fresh server preflight and requires explicit consent bound to the
  complete captured corpus, effective server-egress policy, approved origins,
  privacy disclosures and exact limits;
- identifies egress as the local TabHub server and warns that browser VPN/proxy
  routing may differ;
- displays GET-only, no-cookie/no-credential/no-redirect behavior, robots and
  two-second cadence, page/depth/time/byte/cost caps, the exact
  `maxPages + originCount` network-action cap, and daily remaining/reset values;
- invalidates consent on every material input or preflight change, including a
  response that loses an in-flight race;
- keeps acquisition outcome, final G8 outcome and `runLiveSuccess` distinct;
- renders ordered action provenance, per-source usability, counters,
  checkpoints, acquired-versus-captured evidence, omissions and typed terminal
  outcomes without exposing sensitive URL/DNS/body/key material;
- offers only the closed persisted exact-tab captured-only fallback and never
  navigates, captures, retries or starts fallback automatically;
- restores persisted live-run and purge status after reload, including
  historical reads while writers are disabled;
- provides exact `run` and `resource_history` purge controls with safe initial
  focus, confirmation, focus trap, Escape/focus restoration, idempotent resume,
  retry only when allowed, and terminal cache invalidation/redaction.

User judgment remains separate from agent output. W90 does not change user
importance, retention state, tabs, windows, extension protocol or MCP surface.
