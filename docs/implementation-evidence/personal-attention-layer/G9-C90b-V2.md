## Accepted scope

This Vertical-2 packet closes the server-side admission, action and runtime
boundary for C90 live Resource acquisition:

- replay wins before quote/provider reads and two real SQLite writers converge
  on one job/receipt under a held `BEGIN IMMEDIATE` lock;
- every page action is admitted and revalidated against the exact current
  ruleset digest, target Resource and active Resource generation at queue,
  resolution, authorization, reservation, network start and materialization;
- legal path-scoped Resources may admit an origin through an included captured
  seed of the same canonical origin, while every acquired URL remains subject
  to the exact per-action path fence;
- sensitive/private/mismatched URLs fail before DNS or GET;
- provider quote input reserves one syntactically valid worst-case live source:
  8,192-byte URL, 8,192-byte title, 65,536-byte evidence and an ordinal after
  every included, excluded or missing draft row;
- page accounting is backed by immutable reservations and terminal outcomes;
  robots does not consume a page, while a DNS-blocked reserved page does;
- reconciliation runs before empty work and in `finally`; abort prevents the
  next action and lease renewal, and every post-start returned/thrown abort is
  terminalized as an ambiguous request outcome;
- route wakeup is proven independently of the 60-second polling interval;
- `SafePublicHttpClient` remains a closed server-internal dependency whose sole
  direct importer is the C90 coordinator.

## Independent correction loop

The initial green candidate was rejected with five P1 findings and two
unverified concurrency/runtime boundaries. R2 closed exact action membership,
full source metadata sizing, reservation-backed accounting, post-start abort
ambiguity, a real two-writer race and exclusive wake proof.

R2 was then rejected with two remaining P1 findings: bare-origin-only preview
made path-scoped Resources unusable, and the synthetic quote ordinal ignored
excluded/missing manifest rows. R3 added both rollback tests and fixes. Expanded
verification then found one final P1 import-graph regression: `app.ts` directly
type-imported the closed HTTP client. R4 replaced it with an indirect
coordinator-options type without changing runtime behavior.
