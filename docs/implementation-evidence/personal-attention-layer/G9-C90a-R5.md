## Accepted scope

R5 is the additive correction required after the frozen schema-25 purge command
proved unable to wait for and acknowledge physical C90 work before freezing its
deletion plan. It adds a durable schema-26 intent phase ahead of the unchanged
schema-25 command/executor:

- a permanent, idempotent purge intent owns exact run, action and job wait
  snapshots before command creation;
- `resolution_started` waits are bounded by the fixed DNS deadline rather than
  consent expiry;
- `started` actions use two-phase abort acknowledgement: persist request, signal
  and await the exact tracked execution outside SQLite, then recheck and persist
  one terminal proof;
- response-winning races adopt the real terminal event; missing or stale
  execution remains waiting and is never represented by synthetic success;
- prepublication and resource-research job drains are event-owned and preserve
  provider/reservation accounting, including final zero settlement and UTC-day
  carryover;
- only a fully reconciled `ready` intent may atomically link the frozen
  schema-25 command; legacy schema-25 terminal commands are adopted without
  replaying destructive work;
- the generated schema-26 mutation-fence catalog closes INSERT, UPDATE and
  DELETE surfaces for every table in the privacy-purge target closure;
- completion retains only safe counts/digests and lifecycle tombstones. URL,
  DNS, response body/text, capability and provider material cannot survive the
  declared deletion closure.

The production mutation guards were not weakened. Later regression maintenance
keeps explicitly schema-25 negative tests at migration ceiling 25 rather than
manufacturing a schema-26 bypass.
