## Accepted scope

G8 accepts the ordered packet chain
`C80 -> C81 -> C80r -> C82a -> C82b -> {W80a, C82c} -> C82d -> A80 -> W80b`
plus the gate-level forget-lifecycle and full-regression proofs.

The accepted product boundary is captured-only Resource research:

- a user starts from a canonical page or persisted Resource;
- preflight resolves the selected captured corpus and reports missing evidence;
- only explicitly selected, already-open physical copies may be captured;
- the final immutable source manifest, provider run, report, evidence and
  refinement history are persisted and replayable;
- privacy-sensitive context is excluded unless explicitly shareable;
- G8 itself never opens, navigates or fetches a URL;
- G9 remains the separately consented bounded-live-acquisition gate.

## Gate-level defect found and corrected under TDD

The first real Chrome preflight returned `LOCAL_CAPABILITY_REQUIRED` although
the relay was connected. The web-session cookie was being issued with
`Path=/api/local`, so the browser correctly omitted it from `/api/research`.

The accepted correction is deliberately narrow:

- issue the active session cookie with `Path=/api` and the unchanged
  eight-hour lifetime;
- emit a same-name expiry cookie for legacy `Path=/api/local`, preventing an
  older, more-specific cookie from shadowing the new value on local routes;
- retain the existing HttpOnly, SameSite and capability-validation boundary.
