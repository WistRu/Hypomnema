## Accepted behavior

G6 adds an explicitly opt-in personalization layer without changing the G5
default order. Page and Resource lists support `my`, `ai`, and `recommended`
priority modes plus an independent needs-review filter. Ordering is computed
before pagination and remains total through the existing secondary sort,
normalized browser/resource identity, and physical row ID. Canonical logical
preferences and physical browser copies remain distinct: priority writes are
deduplicated by logical page, while activation and close commands still target
the exact physical tab in its owning browser.

Personal rules use the frozen deterministic EN/RU grammar and the shared strict
AST. Preview is read-only, bounded, and tied to the exact submitted draft,
active reference, and active AST hash. Save creates an inactive immutable
version; activate, disable, reset, and rollback require a separate preview and
explicit confirmation. Recompute is a separate durable job action and is never
started implicitly by a lifecycle mutation.
