## Packet outcome

`W80b` completes the first-party captured-research surface in existing Library
drawers. Page, Resource and selection targets can open a paginated report
history, inspect one exact immutable version, follow parent/head identities,
save an explicit next action as personal context and start a parent-bound refine
run without adding a top-level route.

History stays readable when the research writer is disabled. Start, cancel,
next-action writes and refine remain hidden or unavailable in that state,
including after a capability flip with cached Resource resolution. A failed or
partial latest attempt is shown independently and cannot hide the last
successful report. Current-fresh, last-successful and latest-published head
buttons fetch the exact detail even when it is outside the loaded page.

## Evidence, privacy and truthful state

The detail view renders the closed dossier, coverage, claims, inference
rationale, typed evidence state and retained identities, source/snapshot
digests, safe locators/excerpts and complete provenance/usage. Report text and
excerpts are bounded/collapsible. A redacted report hides dossier, report text,
claim/rationale and locator/excerpt/URL/title material, while retaining the
allowed claim/evidence IDs, ordinals, kinds, states and digests plus provenance
and usage audit. Privacy canaries remain absent.

Cost formatting preserves small non-zero values such as `0.004` instead of
displaying `$0.00`. Moving head membership is rebased from the authoritative
first history page, so an open parent detail cannot retain stale current-fresh
or last-successful badges after a child publication. Conflicting duplicate
report/version rows fail closed with an actionable retry.

Next-action saving requires one explicit suggested step, defaults to
`local_only`, supports `share_with_ai`, uses the correct page/Resource context
command and never invents a shared selection write. Unknown-outcome retry keeps
the same idempotency key; success clears the attempt. Refine binds the selected
path report server-side, reuses W80a preflight/confirmation/progress, compares
old and proposed coverage and cannot leak state across target/report changes.

## Accessibility and localization

The drawer restores focus, labels async states and traps focus. A nested
`Escape` closes only research history and restores its trigger instead of also
closing the parent TabDrawer. EN/RU cover all closed research states,
publication statuses, reasons, latest-run statuses, client errors, numbers,
dates, durations and small costs; mounted locale switching was exercised.
