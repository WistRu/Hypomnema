# TabHub

Личный менеджер вкладок и страниц одного пользователя: локальный сервер, расширение браузера, Library и агентский доступ через MCP. Этот файл — глоссарий, не спецификация.

## Language

### Источники ИИ

**Provider**:
Модель, которую локальный сервер вызывает сам (платно, по feature-флагу) для AI priority, summary и research. Сегодня — только Anthropic.
_Avoid_: «ИИ» без уточнения, LLM, модель

**Agent**:
Внешний ассистент (Claude Code, Codex и т.п.), который работает с TabHub через MCP по явному запросу пользователя. Его записи помечаются `actor=agent`.
_Avoid_: бот, ассистент, «ИИ» без уточнения

**On-behalf-of-user write**:
Запись, которую Agent делает от имени пользователя (контекст, intent, «моя важность»). Не является AI-оценкой.
_Avoid_: AI assessment, автооценка

### Ввод в эксплуатацию

**Rollout**:
Момент, когда ежедневно используемый локальный сервер работает на новой сборке с мигрированной боевой базой `data/tabhub.sqlite`.
_Avoid_: деплой, релиз, прод

**Trial week**:
Семь дней реального использования после Rollout без отката (все новые флаги остаются включёнными).
_Avoid_: UAT, бета, пилот

**Rollback**:
Выключение новых feature-флагов на той же схеме базы. Восстановление из backup — не Rollback, а отдельное явное поручение пользователя.
_Avoid_: откат базы, restore

**Deployment waiver**:
Явное решение пользователя не выкатывать конкретный модуль; модуль остаётся выключенным, его gate остаётся открытым.
_Avoid_: «пропустить проверку», «принять как есть»
